# Event Booking Management System v3.0

A complete Full Stack Event Booking Management System built with Django REST Framework and React.js.

## 🚀 Features

- **Admin Module**: Dashboard with real-time stats, event management (add/edit/delete), system-wide booking visibility, and reporting.
- **Client Module**: Explore events with search/filter, interactive booking with personal details, personal ticket wallet, and QR code integration.
- **Authentication**: Role-based access control with JWT (JSON Web Tokens).
- **Responsive Design**: Modern, mobile-first UI using Tailwind CSS.

## 🛠️ Project Structure

- `backend/`: Django REST Framework API
- `frontend/`: React.js Application

## 🏁 Getting Started

### Backend Setup
1. Navigate to `backend/`
2. Install requirements: `pip install -r requirements.txt`
3. Run migrations: `python manage.py makemigrations` and `python manage.py migrate`
4. Start server: `python manage.py runserver`

### Frontend Setup
1. Navigate to `frontend/`
2. Install dependencies: `npm install`
3. Start development server: `npm start`
